# Tasks

The work is on `change/boom-keeps-decisions-in-a-database-on-the-machine`,
cut from `bolt/boom-holds-the-rules-agents-read`. The rules are
`docs/architecture/core.md` at this place's base (core.1 to core.7);
the decisions record 0005 and record 0006. Every test named here is a
case of `boom:test`. A test runs commands through `boom::cli::run` in a
folder of its own made by `tempfile`, with the tests' `SoftKeys`
(design 8), unless the task says it runs the binary; it reaches no
network, no hardware key and no OpenSSH, and its keys are made when it
runs, never committed (core.3). Each test is named for the spec scenario
it proves and goes into the file its task names.
