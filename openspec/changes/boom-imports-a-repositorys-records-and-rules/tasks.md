# Tasks

The work is on `change/boom-imports-a-repositorys-records-and-rules`,
cut from `bolt/boom-holds-the-rules-agents-read`. The rules are
`docs/architecture/core.md` at this place's base (core.1 to core.7);
the decisions records 0005, 0006 and 0007. Every test named here is a
case of `boom:test`. A test runs commands through `boom::cli::run` in a
folder of its own made by `tempfile`, with the tests' `SoftKeys`, as
the crate's tests do. Every MADR file, rules page and drafts file a
test imports is written by that test, from a string in its code, into
its own folder: no test reads a Markdown file of the tree (core.5;
design 10). Each test is named for the spec scenario it proves and
goes into the file its task names.
