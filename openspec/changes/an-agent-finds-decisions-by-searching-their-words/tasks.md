# Tasks

The work is on `change/an-agent-finds-decisions-by-searching-their-words`,
cut from `bolt/boom-holds-the-rules-agents-read`. The rules are
`docs/architecture/core.md` at this place's base (core.1 to core.7);
the decisions records 0005, 0008 and 0009. Every test named here is a
case of `boom:test`. A test runs commands through `boom::cli::run` in a
folder of its own made by `tempfile`, with the tests' `SoftKeys` and
`Place` (`crates/boom/tests/support/mod.rs`); it reaches no network, no
hardware key and no OpenSSH, its keys are made when it runs, never
committed (core.3), and every page, folder, drafts file and
`.config/boom.toml` it reads it writes into its own folder from a
string in its code (core.5). Each claim a test proposes takes a
scenario and a body written so that only the fields its scenario names
hold the words it searches, since the tests' `SCENARIO` holds `amount`
and `currency` (design 8). Each test is named for the spec scenario it
proves and goes into the file its task names. `boom query` keeps every
word and JSON field it gives now.
