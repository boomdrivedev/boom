# Tasks

The work is on `change/boom-serves-its-commands-to-agents-over-mcp`,
cut from `bolt/boom-holds-the-rules-agents-read`. The rules are
`docs/architecture/core.md` at this place's base (core.1 to core.7);
the decisions records 0006, 0009 and 0011, and flume's `flume mcp`
(`crates/flume/src/commands/mcp.rs` on flume's main), whose design
`boom mcp` copies (design 1). Every test named here is a case of
`boom:test`. A test drives the server through `boom::mcp::serve` in a
folder of its own made by `tempfile`, with the tests' `SoftKeys` and
`Place` (`crates/boom/tests/support/mod.rs`); it reaches no network, no
hardware key and no OpenSSH, its keys are made when it runs, never
committed (core.3), and every `.config/boom.toml` it reads it writes
into its own folder from a string in its code (core.5). Each test is
named for the spec scenario it proves and goes into the file its task
names. Every answer keeps the words and JSON fields it gives now, and
only adds to them. No task adds a dependency (core.6).
